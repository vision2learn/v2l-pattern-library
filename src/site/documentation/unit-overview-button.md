Though it is shown here as a standalone component, the unit overview button should be part of a [tab group](/documentation/tabs), as the child of a list-item.

This component features a semi-transparent background in order to harmonise it's colour scheme with it's parent section without needing to adjust colour values in CSS. This means the component can be placed in sections of varying background colours and look good.

At smaller viewport sizes, the component consumes 100% of it's parent's width and multiple buttons will stack on top of one another. A "plus" icon is shown to make the user aware that additional content will be shown when the button is pressed. When the viewport is large enough, the component becomes a large, circular button.

The use of subtle drop shadowing on the component is designed to make it appear more clickable to the user.
