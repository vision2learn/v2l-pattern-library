The ```header``` component is used by **all** courses and contains key navigational information for helping the user orient themselves during the course.

In addition to this, the [```pagination```]() component is included as a sub-component of the ```header```.

This is in keeping with the [W3C specification for the ```<header>```]({{ references.mdn }}) element.
