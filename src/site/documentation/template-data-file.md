tabledata:
  - 
    key: "course"
    datatype: String
    required: true
    desc: The course name. This must match the folder name defined in `_data/courses`.
  - 
    key: "tags"
    datatype: String
    desc: Metadata used by the system; can be anything as long as it's unique. May be removed in future.
  - 
    key: "level"
    datatype: Number
    required: true
    desc: The level of the course.
  - 
    key: "dotnetID"
    required: true
    datatype: Number
    desc: Used by the `CourseStructure.xml` file which is automatically generated by the system. Can be a dummy value while the course is in development.
  -
    key: "year"
    datatype: Number
    required: true
    desc: The year the course was created.
  -
    key: "shortcode"
    datatype: String
    required: true
    desc: Corresponds to folders where assets can be stored for this course, namely in the `images` and `js` folders.
  - 
    key: "learningoutcomes"
    datatype: Boolean (true/false)
    desc: If true, will generate the "Learning Outcomes" section on Unit 1 > Session 1 > Page 2. A corresponding Learning Outcomes PDF will be required for the course.
  - 
    key: "goals"
    required: true
    datatype: Array
    desc: |
      Sets the content of the "Your learning goals" section shown on Unit 1 > Session 1 > Page 2. This key can have 2 sub-keys: `will` and `can`, which are both arrays. These populate "The learner will" and "The learner can" subsections of the "Your learning goals"
  - 
    key: "courseFeatures"
    datatype: Array
    desc: | 
      Override the default Course Features section shown on Unit 1 > Session 1 > Page 1. Do not use if you require the default Course Features section to display.
      
      Options are: 
        - on the web
        - quick quiz
        - summary
        - stretch
        - key point
        - time to think
        - read more about it
        - watch
        - case study
        - time to practice

  - 
    key: "whatyoulearn"
    datatype: Array
    desc: | 
      Display the "What you will learn" section on Unit 1 > Session 1 > Page 2. The contents of this array will be output as a bulleted list.
---

The Template Data File is required to correctly build a course and is written in JSON format, which is similar to YAML in that is based on key/value pairs but the formatting is different, as shown in the example below.

## Example Template Data File

```json
{
  "course": "it-user-skills-level-2",
  "tags": "it-user-skills-level-2",
  "level": 2,
  "dotnetID": 134,
  "year": 2020,
  "shortcode": "it2",
  "learningoutcomes": true,
  "why": "IT User Skills Level 2 will help you to develop your skills in a range of IT software programmes. Each Unit focuses on an element of IT and will also help you to develop your general IT knowledge and skills. \n\nEach unit is broken down into sessions and focuses on a specific element of IT which will enable you to develop your skills and understanding of different types of office software and the tasks that they can be used for. These units will also help you to develop your general IT knowledge and skills.",
  "goals": {
    "will": [
      "Enter and combine text and other information accurately within word processing documents",
      "Create and modify layout and structures for word processing documents",
      "Use word processing software tools to format and present documents effectively to meet requirements"
    ]
  },
  "courseFeatures": [
    "on the web",
    "quick quiz",
    "summary",
    "stretch",
    "key point",
    "time to think",
    "watch",
    "time to practice",
    "read more about it"
  ],
  "whatyoulearn": [
    "Approaching a task",
    "Using Microsoft Office",
    "Word Processing software",
    "Inputting text and working more efficiently"
  ]
}

```
