**Jack:** So, what are the advantages and disadvantages of functional, object oriented and other coding types.

**Leah:** Let’s start by looking at Functional coding

The Advantages of Functional coding are:

- It’s easy to debug [no side effects or hidden inputs or outputs]

- Functions are easier to understand because they do not affect any variables outside of themself.

The Disadvantages of Functional coding are: 

- The type of function used can reduce the readability of the code.

- Using recursive functions instead of loops can take a while to learn.

**Jack:** Now let’s look at Object Oriented Programming [OOP]

The Advantages of Object Oriented Programming are:

- It is very mature and professionally appreciated. 

- It is also good for making sophisticated software.

The Disadvantages of Object Oriented Programming are: 

- It involves a steep learning curve.

- Large programs end up with slower operating speeds.
