# Frontend Development Success Criteria

*As a Frontend Developer I want*...

- A documented codebase of reusable styles/patterns/components
- The system to use semantic HTML
- To follow [Inclusive Design principles](https://www.microsoft.com/design/inclusive/)
- The system to conform to [WCAG2.1 Guidelines](https://www.w3.org/TR/WCAG21/)
- The system to work well with different input methods (mouse + keyboard, keyboard only, touch)
- The system to follow responsive design best practice
- To support older/legacy browsers with basic functionality through [Progressive Enhancement](https://en.wikipedia.org/wiki/Progressive_enhancement)
