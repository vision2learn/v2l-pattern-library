On this page you’ll be introduced to process maps. A process map is a **picture** of the sequence of steps in a process. 

ClickTap along the slider to the rightbelow to learn more about mapping processes.

### Starting to map a process

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide1.svg)

It is possible to use different boxes or symbols to represent different types of activity or different steps.

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide2.svg)

Step-by-step pictures can be used to describe a workplace process as it currently operates or as it could operate in the future.

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide3.svg)

This helps people to understand what is currently happening in a process and helps identify what needs to be done to make improvements. 

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide4.svg)

It is important to know that before starting to map a process you need to be clear about the **purpose** of the process. 

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide5.svg)

This means identifying the **output** (product or service) that the work process is designed for, who receives the outputs and understanding what happens to inputs (materials, information or documents).

  * ![Starting to map a process](../../images/unit01/session03/pg2-slide6.svg)

The aim is to be clear about what is **flowing** through the process and to be able to follow this activity.

### Symbols and terminology

One popular method of process mapping is the creation of **flowcharts**. 

A flowchart provides a method for mapping the interlinked activities and tasks that form a process. It can help organisations to detect any problems that occur in processes.

Flowcharts work using symbols. ClickTap each symbol in the table below to learn more.
