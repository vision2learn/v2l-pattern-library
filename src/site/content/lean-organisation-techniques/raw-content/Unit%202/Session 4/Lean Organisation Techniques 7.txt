# Standard operating sheets (SOS)

Pages:

  * __
  * __

An organisation committed to standardisation may use **standard operating sheets** (SOS). 

Because these sheets will be reviewed and updated and amended, it is important that issue numbers and dates are recorded. Employees can then be sure that they are working with the up-to-date procedures. 

On the right is an example of a standard operating sheet. 

#### Standard operating sheet

**SOP FOR: ________________**

**Photograph/sketch of the work area**

**Method: Element no** Description of work activity Distance moved Tools used Time taken

#### Step number 

Each step is numbered, indicating the correct order in which things should be done. 

#### Operation description 

A description of the actions to be undertaken in each step. 

#### Time 

Manual time/automatic time/walking time 

An indication of what employees’ upper limits are for their process(es).

#### Process capacity 

Precise information about the time required for employees’ actions. 

#### Set up time 

Information for employees about how long it will take to be ready for production. This must be considered when forecasting production figures.

#### Tool change time 

Information about how long it takes to make tool changes. This also needs to be considered when forecasting production figures. 

#### Tool life 

The tool life determines when tool changes are going to be required. This influences the whole production process.

* * *

Other forms of documentation are used alongside SOS sheets. These include flowcharts and process maps, visual management techniques (such as photographs and diagrams) and Total Productive Maintenance checklists. The use of multiple complementary improvement techniques is a commonly used business improvement technique. 

It is important to make the distinction between an **operation** and the **main step of a process**. For example, when an item is being manufactured, there are hundreds of operations, each made up of **sub-operations**. Each operation is part of a group of operations, called a **step**.

#### In summary ![Summary](../../images/icons/icon-summary.svg)

Standard operating sheets (SOS) are used by organisations to keep a record of their processes as part of their commitment to standardisation. Standard operating sheets record a description of the work activity, the distance moved, the tools used and the time the activity takes. Other forms of documentation, such as maps, photographs and checklists, are usually used alongside standard operating sheets. The sheets are reviewed, updated and amended over time.
