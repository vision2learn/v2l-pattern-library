# Red tagging 

Pages:

  * __
  * __

When abnormal conditions that require attention are identified (during the ‘Clear Out’ stage), they need to be recorded in a way that can be clearly seen. A **red tag** is attached as close to the abnormality as safely possible.

The colour red is usually associated with danger or a hazard. Using red tags is a way of emphasising the need to see and act upon the abnormality.

#### Safety critical 

Fraying computer cables and other trip hazards should be tagged. 

![Safety critical](../../images/unit02/session02/pg7-safety.svg)

#### Quality critical items 

Damaged tools and faulty calibration must be tagged. 

![Quality critical items](../../images/unit02/session02/pg7-quality.svg)

#### Broken items 

Broken items, such as damaged or defective equipment must be tagged. 

![Broken items](../../images/unit02/session02/pg7-broken.svg)

#### Homeless items 

Essential items should go to a designated place and non-essential items should go to a quarantine area. Homeless items should be tagged. 

![Homeless items](../../images/unit02/session02/pg7-homeless.svg)

#### Inventory 

Inventory such as raw materials and work in progress may need to be tagged. 

![Inventory](../../images/unit02/session02/pg7-inventory.svg)

#### Physical factors 

Floors and storage areas are examples of physical factors that may need to be tagged. 

![Physical factors](../../images/unit02/session02/pg7-physical.svg)

‘Invitations’ to take part in the redeployment activities are sent to everyone with a possible interest so that the process is inclusive. The aim is to conduct the redeployment work efficiently and promptly in order to minimise disruption. Action must be taken if any items are found to be different from their required condition. 

Any non-essential items should be held in a designated **quarantine area** for a defined period (such as 3 months). This prevents the items from hindering performance without having to throw them away. If it is decided that an item is not wanted, at the end of the quarantine time it can be ‘auctioned’ and used in other work areas.

### The red tag log

Every work area should have a **red tag log**. The log provides a systematic way of tracking the progress of improvement. 

Ultimately, the red tags should be logged and then permanently eliminated. To do this successfully the staff in the work area must be very thorough. If any items are of uncertain designation they should be tagged and addressed.

Here is an example of a red tag log. 

Red Tag Log Record Sheet 

Tag No Name of item  Location  Action code  Date tag attached  Tag attached by (name) Date action taken

**Action code:**

1 = Move to tag area 

2 = Return to area 

3 = Remove and dispose 

4 = Store distant to area 

5 = Other (state)
