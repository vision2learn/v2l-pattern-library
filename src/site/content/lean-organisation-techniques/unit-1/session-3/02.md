      In the first session of this Unit the ideas of value adding, non-value adding and waste were introduced. It is worth exploring these ideas in a little more detail before you create your own process map. They can prove very helpful when seeking to understand processes and process maps.

      Lean organisations focus upon value. This is value as it is perceived by the customer. The emphasis on what customers and consumers value should shape the thinking and actions of lean organisations. This is certainly true for process mapping activities and using process maps to improve performance.

      People put different values on different things. The challenge for a lean organisation is to know the way its customers place a value on its products or services. Lean organisations aim to deliver value to customers so it is important that they know what is valued.

    subInc:

      content:
        - 
          title: Value adding
          copy: |
            If an activity is to be value added (VA) it must meet all three of the criteria listed below

            * The customer **must** be willing to pay for the activity
            * The activity **must** transform / positively change a product or service in some way
            * The activity **must** be done correctly first time.

            To add value to a process then all the actions / activities / equipment / people / processes / organisations and any other relevant resources **must** meet all three criteria.

            When activities and processes work in this way they are making a direct contribution to customer value.
          img: /images/svg/LeanManagement/LM_U1_S3_p2_Accordion_1.svg
        - 
          title: Non value adding
          copy: |
            If an activity or process fails to meet all three of these criteria then it may be classified as non value adding. It could be that:

            * The customer will not pay for it.
            * The specific activity has not transformed the product or service.
            * The activity was not done correctly first time.

            In these cases the activity or process has wasted time or effort from a customer perspective.

            For many organisations it is helpful to differentiate between two types of non value added. These are **Business Non Value Added** (BNVA) and **Non Value Added** (NVA) or waste. ClickTap the toggles below to read more. 
          img: /images/svg/LeanManagement/LM_U1_S3_p2_Accordion_2.svg
        - 
          title: Business non value added
          copy: |
            These are the wider activities that a business or organisation must undertake in order to be able to do the value adding activities. These activities add no discernible value from the point of view of the customer. Therefore, an organisation may comply with financial regulations, perform tasks that meet legal requirements, or do things to attract new customers. None of these may add value for a current customer.
        - 
          title: Non value added
          copy: |
            These are activities that do not add value and are not requirements of running a business (BNVA). The possibilities here are extensive. They include

            * Rework and repair
            * Duplication of work on a single task
            * Waiting / excessive down time / delays
            * Overproduction
            * Excessive inspection / paperwork / storage / counting
            * Excessive steps to complete a task (over processing).
