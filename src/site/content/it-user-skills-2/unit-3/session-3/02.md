    title: Mathematical and Statistical functions
    theme: t-bg-primary
    copy: |
      Mathematical functions include some of the more complex formulas you can use within Excel. 
      
      Statistical functions can help you to summarise your data. There are many statistical formulas you can use in Excel and the main use of such formulas is to track data ranges, find averages and find minimum / maximum values.

      Scroll through the slides below to learn about some of the most useful ones.

    subInc: 
      type: slider
      title: 
      slides:
        -
          title: The SUM function
          text: |
            This is a function that will help you to quickly add up rows or columns of numbers.  This is done by selecting a range of data and using the AutoSum button.
          img: placeholder_icon.svg
        -
          title: The SUBTOTAL function
          text: |
             The SUBTOTAL function can be used to create summary data. You can use this feature to subtotal data in a sorted list.
             
             The SUBTOTAL function can be used to manually enter subtotals. It can also be used as an alternative to the SUM function to exclude filtered data in calculations. Excel automatically uses the SUBTOTAL function when you click AutoSum to total filtered data. 
          img: placeholder_icon.svg
        -
          title: The ROUND function
          text: |
            You can use this function to round off a number into a value you prefer to see.
            
            For example, if you have a number like 873.32935540 in cell F10, this can look untidy and confusing. You can use =ROUND(F10,3) to shorten the number down to 873.329 (showing only 3 decimal places. 
          img: placeholder_icon.svg
        -
          title: The AVERAGE function
          text: |
             As you might have already guessed, this function helps you to calculate the average value across a range of data.  

             This function will work with any number of values, as long as you know the cell references at the beginning and end of the range. 
          img: placeholder_icon.svg
        -
          title: The COUNT function
          text: |
            This function will simply count up the number of entries across a range of cells. In the previous example, we knew that the range of cells from B2 to B9 contained eight entries – but, what if we wanted to know how many entries were in cells B51 to B693?
            
            Type =COUNT(B51:B693) and Excel will count them for you. 
          img: placeholder_icon.svg
        -
          title: The MIN/MAX function
          text: |
            These are statistical functions, which you can use to calculate the smallest and largest number in a range of data. 

            The MIN function returns the smallest number in a set of values.

            Similarly, the MAX function allows you to calculate the largest number in a range of data.
          img: placeholder_icon.svg
