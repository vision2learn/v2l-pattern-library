          title: Cell references
          copy: |

            A cell reference tells you the location of a cell within your spreadsheet. It consists of the column letter and row number of the cell.

            For example, the cell highlighted to your right would be cell B2 because it located in column B, row 2.

            Cell references are really useful when creating formula because they tell Excel where the data you want to be used in the formula is located. That way, if the data in the cell changes, the result of your calculation will be updated automatically and you won’t have to work everything out again. 
          img: /images/svg/placeholder_icon.svg
        -
          title: Using cell references
          copy: |
            You can type any cell or range reference directly into a formula. You can also point and click with your mouse as you type a formula to enter a cell or range reference.

            One of the simplest Excel formulas is a direct reference to another cell. For example, if you click in cell B24 and enter the formula =A5, Excel displays the current value of cell A5 in cell B24. A5 is known as an input cell, containing data that is used elsewhere in the worksheet.
          img: /images/svg/placeholder_icon.svg
        -
          title: Using a row or column reference 
          copy: |
            You can also enter a reference to an entire row or column. To do this, use the row number or column letter as both halves of the reference e.g. =B:B for column B, or =2:2 for row 2.

            You can also use this method to select multiple rows or columns, for example =B:K selects every cell in columns B to K; =10:13 selects every cell in rows 10 to 13. 
          img: /images/svg/placeholder_icon.svg
        -
          title: Absolute and Relative cell references
          copy: |
            By default, a spreadsheet cell reference is relative. This means that if the cells that contain the data used in the formula are copied and pasted to other cells, the cell references in the formula or function change to reflect the function's new location.

            In contrast, an absolute cell reference does not change when a formula is copied and pasted to other cells. 
          img: /images/svg/placeholder_icon.svg
        -
          title: Using a Relative reference
          copy: |
            By default, formulas in Excel contain relative references. This means that the cells that are referred to in a formula will automatically change if you move their content somewhere else. For example the following formula is entered into cell D13, to total the contents of cells D7 through to D12:

            =SUM(D7:D12)

            If the contents of D7:D12 were copied and pasted into cells A6:A11, then the formula in D13 would automatically change to read:

            =SUM(A6:A11) 
          img: /images/svg/placeholder_icon.svg
        -
          title: Using an Absolute reference
          copy: |
            Sometimes, you might want to make sure that a formula continues to refer to the same cells, even if the content in these cells is moved.

            To make sure the reference to this cell does not adjust when a formula is copied or moved, change it from a relative reference to an absolute reference using dollar signs within the cell address.

            =A5 is a relative reference.

            =$A$5 is an absolute reference.
          img: /images/svg/placeholder_icon.svg
