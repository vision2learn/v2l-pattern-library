    title: Sorting data
    theme: t-bg-primary
    copy: |
      Sorting your data and displaying only the required values can really help to improve data analysis.  Scroll through the slides below to learn more. 

    subInc: 
      type: slider
      title: 
      slides:
        -
          title: Simple sorting
          text: |
            Sorting data rearranges it to make it more accessible. 
            The two simple sorting options are:
            * Sort Z to A Highest to lowest (sorts data from highest to lowest) and 
            * Sort A to Z Lowest to highest (sorts data from lowest to highest)
            
            These options are useful if you want, for example, to quickly arrange a list of names alphabetically.

          img: it2/it2_u3_s3_p4_slide1.svg
        -
          title: Perform a simple sort
          text: |
            1. Click on a cell in the column you want to sort
            2. Go to the *Data* tab and the *Sort & Filter* group
            3. Click the *Sort A to Z* or *Sort Z to A* button. Excel sorts all the data in your selected column and moves the rows of data in adjacent columns to keep data together. 

          img: it2/it2_u3_s3_p4_slide2.svg
        -
          title: Complex sorting
          text: |
            There are also more complex sorting options in Excel. These options let you sort your data by multiple criteria. 
            
            This is useful if you want to arrange data by dates and then by alphabetical order. 

          img: it2/it2_u3_s3_p4_slide3.svg
        -
          title: Perform a complex sort
          text: |
            1. Select any cell in the range to sort all the data, or highlight a selection of cells
            2. Go to the *Data* tab and click the *Sort* button in the *Sort & Filter* group
            3. The *Sort* dialog box opens. Open the drop-down list in the *Sort by* box and select the column by which you first want to sort your data.
            4. Then specify the sort criteria from the *Sort On and Order* drop-down lists.
          img: it2/it2_u3_s3_p4_slide4.png

    title: Linking data and Hyperlinks
    theme: t-bg-primary
    copy: |
      If you are using several worksheets in your spreadsheet, the chances are that the data contained across these worksheets is connected in some way. It is often useful to be able to *link the data* you have stored in these worksheets.
      
      When you copy and paste data, it may be useful to create a link between the source file and the destination file. If information is linked in this way, whenever you update the original information (source file), the data in the destination file will be automatically updated. To do this you would add a *hyperlinks* to your spreadsheet documents.
