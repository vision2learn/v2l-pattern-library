        -
          title: Simple sorting
          text: |
            Sorting data rearranges it to make it more accessible. 
            The two simple sorting options are:
            * Sort Smallest to Largest (sorts data from smallest to largest / A – Z) and 
            * Sort Largest to Smallest (sorts data from largest to smallest / Z – A.
            
            These options are useful if you want, for example, to quickly arrange a list of names alphabetically.

          img: placeholder_icon.svg
        -
          title: Perform a simple sort
          text: |
            1. Click on a cell in the column you want to sort
            2. Go to the Data tab and the Sort & Filter group
            3. Click the Sort Smallest to Largest or Sort Largest to Smallest button. Excel sorts all the data in your selected column and moves the rows of data in adjacent columns to keep data together. 

          img: placeholder_icon.svg
        -
          title: Complex sorting
          text: |
            There are also more complex sorting options in Excel. These options let you sort your data by multiple criteria. 
            
            This is useful if you want to arrange data by dates and then by alphabetical order. 

          img: placeholder_icon.svg
        -
          title: Perform a complex sort
          text: |
            1. Select any cell in the range to sort all the data, or highlight a selection of cells
            2. Go to the Data tab and click the Sort button in the Sort & Filter group
            3. The Sort dialog box opens. Open the drop-down list in the Sort by box and select the column by which you first want to sort your data.
            4. Then specify the sort criteria from the Sort On and Order drop-down lists.
          img: placeholder_icon.svg
