    title: Excel error checker
    theme: t-bg-supporting2
    copy: |
        Excel tries to track errors automatically as you work, usually by displaying a green triangle in the upper left corner of any cell that contains an error. However, you can also use the Excel Error Checker to look for anything else that might be wrong.

    subInc: 
      type: accordion
      content:
        - 
          title: To use the Excel Error Checker. . 
          copy: |
            1. Click on the Formulas tab.
            2. In the Formula Auditing group, click on the Error Checking button.
            3. The Error Checking dialog box will appear. Here, errors will be highlighted and you can get help on how to fix the error!
            4. The error type is displayed, followed by the following list:
            
          img: /images/svg/it2/it2_u3_s6_p2_image1.png
        - 
          title: List of error-checking options
          copy: |
            * Help on This Error: displays information specific to the error type.
            * Show Calculation Steps: demonstrates all steps leading to the error.
            * Ignore Error: allows you to accept the formula as entered, without Excel displaying the Error Checking Options smart tag.
            * Edit in Formula Bar: allows you to edit the formula that is generating the error in the Formula Bar.
            * Error Checking Options: opens the Options dialog box, where you can select the rules governing error checking.
            * Show Formula Auditing Toolbar: displays the Formula Auditing toolbar.

If you want Excel to quickly add up 70, 50 and 50, you could estimate the answer will be between 150 and 200. If the answer is 2000, you know there is an error in your work.

          title: Checking charts and graphs
          text: |
            Key questions to ask when you are checking charts and graphs: 
            1. Do my graph and axis titles accurately describe the data in the graph?
            2. Does my graph show what I expected it to?
            3. Does the chart type present the data in the best possible way?
            4. Are there any bits of data that don’t make sense / follow the trend?
          img: it2/it2_u3_s6_p2_slide3.svg

          title: Display formula errors
          text: |
            It can be useful to see your data displayed as formulas rather than totals and results. This is helpful when checking your formulas are correct. Showing formulas does not change the spreadsheet – just the way it is displayed! To reveal formulas:
            1. Click on the Formulas tab.
            2. In the Formula Auditing group, click the arrow next to the Show Formulas button.
            3. Your formulas will now be displayed!
