    title: Formula errors
    theme: t-bg-primary
    copy: |
        Because of the complexity of some of the formulas and functions within Excel, you may find that sometimes your functions will return errors. There are seven error codes you may see and, depending on the cause of the error, you will either need to revise your formula or change the arguments to reflect a new cell range.

        Excel will display an error value if a formula cannot properly calculate.

        Select the images below to learn about the causes of some of the common error codes and how you can fix them.

    subInc: 
      type: reveal
      content:
        -
          title: "####"
          copy: |
             When you see the error code ####, this is usually because the column that contains the data is not wide enough, or because a negative date or time has been entered. To solve this problem increase the column width or/and apply a different number format.
          img: placeholder_icon.svg
        -
          title: "#VALUE!"
          copy: |
            When you see the #VALUE! error code, this is usually because the wrong type of data has been entered into a cell. To solve this problem, don’t enter text into a cell that requires a number, and vice versa.
          img: placeholder_icon.svg
        -
          title: "#DIV/0!"
          copy: |
            When you see the error code #DIV/0!, this is because the value in the cell is being divided by zero. To solve this problem ensure that the value in the cell is not being divided by zero, and the cell reference does not refer to a blank cell.

          img: placeholder_icon.svg
        -
          title: "#NAME?"
          copy: |
            When you see the #NAME? error code, this is because the text inside a cell is not recognised. To solve this problem, check the spelling of the function or range, ensure that the range that you are directing to contains data, and there is a colon used after range references.

          img: placeholder_icon.svg
        -
          title: "#REF"
          copy: |
             When you see the #REF error code, this is because the cell reference is not valid. To solve this problem check that the referenced cell has not been deleted.

          img: placeholder_icon.svg
        -
          title: "#NUM!"
          copy: |
            When you see the #NUM! error code, this is because the formula or function contains invalid numerical values. To solve this problem check that text has not been entered into the cells used by the function or formula instead of numbers and, the number used is not too large or small for Excel.

    title: Removing circular references
    theme: 
    copy: |
        Circular references occur when a formula refers to the cell in which the formula is stored. For example, if the cell C5 contains the formula =C4+C5, then C5 contains a circular reference. Circular references are usually errors.

    subInc: 
      type: accordion
      content:
        - 
          title: How to check and remove a circular reference
          copy: |
            If an error message about creating a circular reference appears while editing a formula, then you may have created a circular reference by mistake! In this case, you can locate and remove the incorrect reference. 
            1. Click on the Formulas tab.
            2. In the Formula Auditing group, click the arrow next to the Error Checking button.
            3. From the menu that appears, click on Circular references.
            4. Here Excel will list all of the cells within your spreadsheet that contain circular references.
            5. Click on the cell to review the formula. Change the formula in the formula bar so that it no longer contains a circular reference.

    title: Validation lists
    theme: t-bg-supporting2
    copy: |
        During data entry, a validation list forces anyone using your worksheet to select a value from a drop down menu rather than type it – and potentially type the wrong information. When used in this way, validation lists save time and reduce errors.

    subInc: 
      type: accordion
      content:
        - 
          title: How to create a validation list
          copy: |
            1. Click on the cell in which you want to create the validation list.
            2. Click on the Data tab.
            3. In the Data Tools group, click on Data Validation.
            4. The Data Validation dialog box will appear.
            5. Click on the Settings tab.
            6. In the Allow: field, you can select whether you would like your cell to contain whole numbers, decimals, a date or a time.
            7. If you select whole number, you will need to enter minimum and maximum values.
            8. Click OK to apply your data validation list.

    layout: media
    theme: t-bg-primary
    copy: |
      It is a good idea to check the layout and formatting of your worksheet. There a few helpful ways to check that you have made sure your spreadsheet is presented in the most effective way. 

      There are a few simple ways to make sure your worksheet is clear:
      * Always ensure your data corresponds by laying out related data as clear lists, usually in the form of a column
      * Leave a space between the last cell of your column list and its 'total'. This separates the total from the main body of data, making it easier to understand
      * Use titles and subtitles to label your data
      * Consider if you need to format some headings or cells differently to make them stand out.
