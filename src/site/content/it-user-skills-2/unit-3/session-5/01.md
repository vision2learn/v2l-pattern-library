    title: Chart types
    theme: t-bg-supporting3
    copy: |
      There are a number of different chart types that you can use when deciding how you would like to display your data.
      
      Different charts and graphs represent data in different ways, and it’s important that you choose the best type of chart for the data you have. For example, a pie chart might be best to represent data collected in a survey, but a bar chart may be more appropriate for tracking sales figures.  Scroll through the slides below to learn more.

    subInc: 
      type: slider
      title: 
      slides:
        -
          title: Column charts
          text: |
            This type of chart shows a comparison between values in one or more data series, often over a period of time.

            **Do**: Use this chart to show trends over short periods of time, especially if there are only 2 or 3 data series.

            **Don’t**: Use this chart if you have too many different data series. Don’t use this chart if the minimum and maximum values in each data series are massively different. 
          img: it2/it2_u3_s5_p1_slide1.svg
        -
          title: Line charts
          text: |
            This type of chart should be used to show a trend or relationship between values over a long period of time. The individual points flow into a smooth line where you can see the rate of change.

            **Do**: Use a line chart when you have many data points to plot and want to show a trend over a period of time.

            **Don’t**: Use this chart type when you’re trying to show the relationship between numbers without respect to time, or when you only have a few data points in the chart. 
          img: it2/it2_u3_s5_p1_slide2.svg
        -
          title: Pie charts
          text: |
            Pie charts show the relative size of all parts of the whole – for example, the % of people who like a particular sandwich filling. Pie charts have no X-Axis or Y-Axis, and only one data series can be plotted.

            **Do**: Use a pie chart when you only have a few numbers to chart and want to show how each number contributes to the whole.

            **Don’t**: Use a pie chart when your data series includes many low numbers that contribute a very small percentage to the total. In this case, individual pie slices will be too small to compare. 
          img: it2/it2_u3_s5_p1_slide3.svg
        -
          title: Bar charts
          text: |
            Think of a bar chart as a column chart turned on its side. The values appear along the horizontal axis and categories appear on the vertical axis. These charts put more emphasis on ‘winners’ and ‘losers’ rather than the time period. For example, a bar chart could show how well each region has performed in a competition where the goal was raise the maximum amount of money for charity.

            **Do**: Use bar charts to compare a small number of data series.

            **Don’t**: Use bar charts when there are too many data series - you won’t be able to see the difference between the bars! 
          img: it2/it2_u3_s5_p1_slide4.svg
        -
          title: Area charts
          text: |
            This chart type shows lines for parts of a series, adding all the values together to illustrate cumulative change. Unlike line charts, which emphasise the rate of change, area charts show the size of the change.

            **Do**: Use area charts to highlight the size of a change. The charts work well with data organised by time; unlike line charts, area charts can handle many points of data.

            **Don't**: Use an area chart to compare data series that don’t add together – this will lead to a very messy graph! 
          img: it2/it2_u3_s5_p1_slide5.svg
        -
          title: XY (scatter) charts
          text: |
            A scatter graph is a graph of plotted points that shows the relationships between two series of data. For example, plotting daily high temperatures against ice cream sales over the course of a year may show that more ice creams are sold on hot days.
            
            When creating a scatter chart, it is really important that you arrange the data in your worksheet carefully. Make sure that the first column of your data range contains values for the X Axis (horizontal axis), and that the additional columns contain data for the Y Axis (horizontal axis). 
          img: it2/it2_u3_s5_p1_slide6.svg
