      Using folders to organise your files is a great way of grouping similar files together. Over time you can end up with hundreds or even thousands of files and by saving similar files together in one folder it allows you to access them quickly and avoid having  to waste time searching for them.

    copy: |
      When you save a file, you can choose to save it to a folder on your hard disk drive, a network location, a DVD or CD, the desktop or a flash drive. You can also choose to save it in another file format.

      To save your work in your chosen location, you can click to select a folder in the *Save As* dialog box.
      
      1. Click the *File* button (*File menu* on a Mac) and then click *Save As*. The *Save As* dialog box will open.
      2. In the *File* name box, enter a new name for the file.
      3. Use the *Navigation* pane in the *Save As* dialog box to choose where you would like to save the file.
      4. Once you have selected all of your options, click *Save* to save your file in the chosen location.

          title: Print
          copy: |
            You can use this feature to preview the layout of your document and see what it will look like when you print it. To do this:
            1. Click the *File* button (*File menu* on a Mac).
            2. Click the *Print* option.
            3. In the window displayed you can preview each page of your document before you print it.
            4. Here you can select a number of options, including: output type (printer or PDF), the Printer, Paper size and Number of copies that you would like to print. 
            5. If you wish to create a PDF on a Mac, you would select *Save as PDF* from the *PDF* dropdown box at the botton of the Print options window.
            6. You can also set the scaling options to ensure that the data is displayed on the correct number of pages.  For example, ‘fit sheet on one page’ will resize all of the data so that the entire content of the selected worksheet will fit on one page when printed. 

            Under the *Settings* heading in the *Print* section of the *File* tab, you can select whether you would like to print just the active sheets (the ones you have used), the whole workbook (all of the worksheets it includes) or the current selection (any highlighted data).
