        - 
          title: Non-generic file types
          copy: |
            Files saved in newer versions of Microsoft Word will **automatically** have a non-generic **.docx** file type. This means that these files can only be opened by users with newer or recent versions of Microsoft Word.
            
            To ensure that users that have older versions of Microsoft Word, files will need to be saved as a generic file type.
        - 
          title: Generic file types
          copy: |
            Generic file types, such as .doc or .rtf, are more accessible, as you don’t need to have any particular software installed on your computer to view these files. 
        -
          title: Steps to Save As
          copy: |
            1. Click the File button and then click Save As. The Save As dialog box will open.
            2. In the File name box, enter a new name for the file.
            3. Use the Navigation pane in the Save As dialog box to choose where you would like to save the file.
            4. In the Save as type list, click the file format that you want to save the file in. You’ll find the Plain Text and Rich Text Format options in this list.
            5. Click Save.
