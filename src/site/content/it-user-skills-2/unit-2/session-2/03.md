      Check that your document is set at the right size and page orientation to be printed by clicking on the Page Layout tab and using the options in the Page Setup group.

      To preview your document:
      1. Click the File button (File menu on a Mac).
      2. Click the Print option.
      3. In the window displayed you can preview each page of your document before you print it.
      4. Here you can select a number of options, including: output type (printer or PDF), the Printer, Paper size and Number of copies that you would like to print.

      It’s important to select the right orientation when printing different parts of your presentation. By default Microsoft PowerPoint will:

      * Print presentation slides in landscape format
      * Print notes, handouts and outlines in portrait format.

      1. Click the File button (File menu on a Mac) and then select Print from the menu.
      2. Use the Full Page Slides drop-down to select what you would like to print, this might be the slides of your presentation, handouts, an outline or speakers notes.
      3. Click on the Orientation drop down and select either Portrait or Landscape orientation.
      4. When you are happy with your selection, click the Print icon.
