        The first thing you need to do before editing any text is to select it.

        To do this, point with your mouse at the word you want to select and then either double-click with the left mouse button to select a single word, or drag the mouse over the word (or words) to select them.

        Your selected text will appear highlighted on the screen. Once you have highlighted the text, you are ready to edit it.
