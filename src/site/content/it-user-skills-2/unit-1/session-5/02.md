            The Insert Hyperlink dialog box

            In order to link your text to another document, file or webpage, you need to open the Insert Hyperlink dialog box. To do this:

            In your document, select the text that you want to link to another document, file or webpage.

            Click on the Insert tab, then click on the Hyperlink icon in the Links group.

            The Insert Hyperlink dialog box will appear.
          img: placeholder_icon.svg
        -
          title: Step 2

                From the Link to: menu on the left hand side, you have four options:
                * Existing File or Web Page
                * Place in This Document
                * Create New Document
                * E-mail Address

                When you have created your link, click OK to insert your link into your document.
