          title: Guidelines for transferring data
          text: |
            From time to time, you might find that it is useful to include different types of data in your Word documents. For example, you could include an image or a chart from another document.

            When you’re transferring data, it’s important that you follow a number of basic guidelines:

            * Before you import anything into your Word document, position your cursor at the point in the document where you want the data to appear.
            * Make sure you select the correct data or file to transfer.
            * Make sure that the data is in a suitable format for transferring into a Word document.
            * If you are importing a file you should check that the file size isn’t too large, as this will affect the usability of your document.

          title: Presenting documents
          text: |
            One important point to bear in mind when integrating different types of data is the overall presentation of your document.

            When inserting data from other files, you can change the layout of your original document. If your cursor is positioned in the wrong place, this can insert data into your document at the wrong point and spoil the document structure.

            Whether your document is a letter, report or memo, it’s important that any data you import does not affect how suitable the document is for its purpose.

    title: Why use a spreadsheet?
    layout: media
    theme: t-bg-primary
    copy: |
      Spreadsheet files are very useful as they allow the user to compile, sort and analyse a range of information. You can also create calculations based on the data and create a variety of charts and graphs.

      By importing a spreadsheet file into your document, you can present data in a professional, easy to read format. You can even create a link between your document and the Excel data – this means that whenever the data is updated in Excel, the content in your Word document will also update automatically!

      The best way to import spreadsheet data into your work is in .csv format – this is a generic file format available as an option when saving Excel documents.
