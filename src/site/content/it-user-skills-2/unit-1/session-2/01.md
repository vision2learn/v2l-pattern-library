            When you save your documents, you can give them a name to help you to locate and manage your work. As well as giving your documents suitable names, you can also use folders on your computer to file documents into.

          title: Save your files
          copy: |
            When you save a file, you can choose to save it to a folder on your hard disk drive, a network location, a DVD or CD, the desktop or a flash drive. You can also choose to save it in another file format.

            To save your work in your chosen location, you can click to select a folder in the Save As dialog box.
            
            Once you’ve saved your document using the ‘Save As’ method, you can save any further changes by using the Save button above the ribbon at any time.

            To save a file:

            1. Click the File button and then click Save.

            2. If you are saving the file for the first time, the Save As dialog box will open and you will be prompted to select a number of options for saving your file.

            3. You’ll need to give your file a suitable name by typing in the File name: box.

            4. You can also use the Navigation pane in the Save As dialog box to choose where you would like to save the file.

            5. Once you have selected all of your options, click Save to save your file in the chosen location.

          img: /images/svg/placeholder_icon.svg

            When using Microsoft Office 2010, you can choose to share your files with people using an earlier version of Microsoft Office by saving your file in the 97-2003 file format. Your files do not need to be saved in a different format to be shared with people using Microsoft Office 2007.

            To save your Microsoft Office 2010 file in a different format:

            1. Click the File button and then click Save As. The Save As dialog box will open:

            2. In the File name box, enter a new name for the file.

            3. Use the Navigation pane in the Save As dialog box to choose where you would like to save the file.

            4. In the Save as type list, click the file format that you want to save the file in. You’ll find the 97-2003 format option in this list.

    title: File types
    theme: t-bg-primary1c
    copy: |
      File types can either be generic or non-generic. When deciding on a file type, you need to consider who needs to view the document. Which programs do they have access to?

      ### Non-generic file types

      Files saved in Microsoft Word will automatically have a non-generic .docx file type. This means that these files can only be opened by users with Microsoft Word 2010 or 2007.

      Non-generic file types are best used when the people who need to view the document have access to Microsoft Word 2007 or higher.
