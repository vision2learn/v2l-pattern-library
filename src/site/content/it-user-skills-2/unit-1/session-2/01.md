    title: File types
    theme: t-bg-primary1c
    copy: |
      File types can either be generic or non-generic. When deciding on a file type, you need to consider who needs to view the document. Which programs do they have access to?

      ### Non-generic file types

      Files saved in Microsoft Word will automatically have a non-generic .docx file type. This means that these files can only be opened by users with Microsoft Word 2010 or 2007.

      Non-generic file types are best used when the people who need to view the document have access to Microsoft Word 2007 or higher.

      ### Printing your documents

      Once your documents are stored on your computer, you can access them at any time. However there may be times when you need paper versions of your documents. When this happens you can print your documents.
      
      Microsoft Word also allows you to preview your documents on screen before you print them. This lets you see what your document will look like when it is printed.
