          copy: |
            An **archive file** is a collection of files stored in one file. It is not compressed and uses the same amount of disk space as all the individual files combined. When you archive a file, it is moved from one location to another, for example a disk or USB.


            A **compressed file** is a collection of files that are stored in one file and ‘zipped’ so that they use less disk space than all of the individual files combined.
