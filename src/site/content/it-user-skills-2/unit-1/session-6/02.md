          title: Language settings
          copy: |
            Word has both UK and US versions of English loaded onto it. US English spells some words differently to UK English, and this can be an issue when proofing your documents.

            To alter the primary language Word will check your spelling in:
            1. Click on the File tab and click Options from the left hand menu.
            2. The Word Options dialog box will open, select Language from the left hand menu.
            3. Under Choosing Editing Language you can use the Remove and Add buttons to set the correct language.
          img: /images/svg/it2/it2_u1_s6_p2_accordion1.svg
        - 
          title: Custom Dictionary
          copy: |
            When you install Office onto your PC, a dictionary file is also installed for the languages used in your Windows settings. Word uses this dictionary file for spell-checking purposes.

            Although the dictionary is extensive, Word does not recognise all surnames or first names, and it often doesn’t recognise acronyms and technical terms. If you use these words often, you can add them to a Custom Dictionary. Here’s how:
            
            1. Place your mouse over the word you want to add, then right-click on it.
            2. From the menu that appears, select Add to Dictionary.

          title: when using 'Replace'
          copy: |
            The Find and replace function is a very quick and accurate way of making changes to your document.

            However, you should be careful when you use it as Word will search for every instance of the word you ask it to find, and automatically change it for you.
            
            While this is fine in most cases – and what the function is for – imagine that you have asked Word to change all instances of the word ‘night’ to the word ‘fright’. What would happen to words like nightfall, overnight and knight? You could end up creating a lot more work for yourself!
