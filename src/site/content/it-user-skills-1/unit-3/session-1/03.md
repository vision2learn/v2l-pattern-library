      When you are planning a task, it is important to remember that there are certain factors that can have a negative impact on the work you are doing and may prevent you from achieving your goals.

      Scroll through the slides below to learn more.

    subInc:

      slides:

          title: Data protection
          text: |
            Any personal data that you include in your work is covered by **The Data Protection Act (2018)**. If you need to include personal information in your work, you should make sure that you have permission to use it. As you can imagine, your task could be affected if you aren’t able to get permission to use the information you want to or if you use data without permission and get into trouble for it!

            Click to read more about [The Data Protection Act](https://www.legislation.gov.uk/ukpga/2018/12/contents)

          img: it2/it2_u2_s3_p3_ipu_slide_3.svg
        -
          title: Copyright
          text: |
            If your work includes any content that is not your own, you need to be aware of copyright laws. If you do want to use content (some text, an image, etc) that belongs to someone else, you may need to ask their permission before using it. The owner of the content might also want you to include an acknowledgement in your work, in order to confirm the source of the content.

            **The Copyright, Designs and Patents Act 1988** is the main piece of legislation relating to the use of other people’s content.

          img: it2/it2_u2_s3_p3_ipu_slide_4.svg
        -
          title: Software licensing issues
          text: |
            Almost any software application that you buy has some sort of license agreement associated with it.

            Typically, a software license will give you permission to use the software application in accordance with the specific terms of use. A software license will usually outline the following information:
            * The permissions, rights and restrictions relating to the use of the software
            * Liability and responsibility between the software manufacturer and you, the user.
          img: placeholder_icon.svg
        -
          title: Organisational guidelines
          text: |
            Your organisation may have specific guidelines that you need to stick to when working on a task. For example, you might need to follow an organisational house style or a set of specific brand guidelines.

            A house style will specify the type of formatting you need to apply to your work (such as the fonts and font sizes you should use for headings / sub-headings / paragraphs, how content should be aligned, what type of bullet points to use, etc). This helps everyone in the organisation to create work that looks professional and consistent.

            Brand guidelines are similar and will give you information about how to make sure your work reflects the brand of the organisation. This might include things like how to use the company logo or apply company colours to text, etc.
          img: it2/it2_u2_s3_p3_ipu_slide_2.svg
