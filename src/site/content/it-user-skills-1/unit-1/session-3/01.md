    title: Read - Style guide
    theme: t-bg-primary3 i-read
    copy: | 
      When you have applied different typefaces and font sizes to your document, you should check to make sure you have applied them accurately and consistently. A house style or style guide can help you to do this. 

      You can use a style guide to record all of the different formats you want to include in your document, for example the typeface and font size you will use for headings / sub headings / paragraphs, etc. You can then use this to help you check that you have applied the correct formatting techniques throughout your document.

      Take a look at the following example of a style guide:
