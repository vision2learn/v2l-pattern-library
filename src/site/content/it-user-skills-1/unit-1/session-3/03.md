      ### Images

      [//]: # (Position your cursor at the point in the document where you would like to insert the image.
      Select Insert – Picture – From File from the top menu -Insert – Illustrations – Pictures in Microsoft Word 2007-. The Insert Picture dialog box will open. Click on the image below to see an example of the dialog box: Insert Picture dialog box
      Now use this dialog box to navigate to an image file that you want to insert and then click to select the file. Click the Insert button to insert the selected file into your document. The image will now appear in your Word document.
      You can also insert Clip Art into your Word document by selecting Insert – Picture – Clip Art from the top menu. Clip Art is Microsoft’s preset gallery of images and pictures that you can add to your documents.)

    title: Formatting an image
    layout: media
    theme: t-bg-primary
    copy: |
        Once you have inserted an image into your document, you can click to select it and this allows you to format it. You will know when an image is selected, as it will appear with black square handles around it (blue in Microsoft Word 2007).

        For example, when you have selected an image, you can change the position of the image by clicking and dragging it around your document and dropping it into a suitable position.

        You can also change the size of the image by clicking and dragging any of the black square handles that appear around the image when you click to select it. Another way to change the size of an image is to crop it, which involves cutting and removing sections of the image.
