          copy: |

        -
          title: Money
          copy: |

        -
          title: Accuracy
          copy: |

    subInc:

          title: Microsoft Word
          copy: |
            | Advantages | Disadvantages |
            |------|------|
            |Is well suited to create a wide range of documents such as letters, essays and posters  | Despite being compatible with many file types, not all file formats can be used with this software|
            | Contains large amounts of writing and formatting tools to make your documents look more professional | Is not suited to working with or using numerical data |
            | Can be used in conjunction with other Microsoft software packages, such as graphs from Excel | Is not suited to working on presentations |
            | Is widely used and supports a number of file types |   |
        - 
          title: Microsoft PowerPoint
          copy: |
            | Advantages | Disadvantages |
            |------|------|
            | This program enables you to create professional-looking presentations | Does not work well with longer documents or too much text |
            |  You can create and format each presentation slide | Does not have as many uses as Word; it can only really be used for presentations and notes |
            | You can add images and animated effects and colour schemes to engage your audience |  It cannot really be transferred to the other software unlike Word or Excel |
        - 
          title: Microsoft Excel
          copy: |
            | Advantages | Disadvantages |
            |------|------|
            | You can use this program to create and format spreadsheets for budgets or financial reports |  Is not suited to using large amounts of text. Excel specialises in numbers and figures |
            | Automatic updating of values in cells | Should not be used to create presentations |
            | You can store large amounts of data | It can be quite complex and takes a bit of practice to use the more difficult formulas |
            | You can perform complex calculations and create graphs to help you analyse your data | Data can only be displayed in cells |
            | Graphs and tables can be copied into Word or PowerPoint to help provide a visual aid to a leaflet or presentation |  |
