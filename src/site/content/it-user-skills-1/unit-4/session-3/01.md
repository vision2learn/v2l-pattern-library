            To format the decimal places displayed in your spreadsheet, you can either use the *increase/decrease decimal* buttons(s) on the *Home* Ribbon, or open the *Format Cells* dialogue window and select *Number*.
          img: it1/it1_u4_s3_p1_reveal1.png
        -
          title: Currency
          copy: |
            You can format data in your spreadsheet so that is displays as currency. You can either use the *Accounting Number Format* button or from the *Format Cells* dialogue window and selecting *Currency*.
          img: it1/it1_u4_s3_p1_reveal2.png
        -
          title: Percentages
          copy: |
            You can format numbers in your spreadsheet so that they display as percentage values. Applying the percentage format to your data will multiply the cell value by 100 and display the result with a percentage symbol (%). Simple select the *percentage* button from the *Home* ribbon.
          img: it1/it1_u4_s3_p1_reveal3.png

      As well as formatting existing data in your spreadsheet, you can also format cells before you’ve entered any data.
