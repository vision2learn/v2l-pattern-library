    theme: t-bg-primary
    copy: |
        Before you apply any formatting, you need to make sure that you select the cells, row or column that you want to format. You can select a row by clicking on the row number. To select a column, click on the column letter.

        All of the content you type in your spreadsheet (both text and numbers) will display on the page in a certain font type. This refers to the style of the text you are using, and Microsoft Excel has a wide range of different font types for you to choose from.

        You can use the bold, italic and underline options to emphasise bits of your spreadsheet content, to make it stand out more.
        Please select the following images to read more.
