            To change your page orientation, simply click to select the option you prefer.

            You can also use the Scaling section to change the size of your document so that it fits onto a certain number of pages when printed. 

            As well as adjusting the percentage size, you can also tell Excel to print your document on a specified number of pages.
          img: placeholder_icon.svg
        -
          title: Margins
          text: |
            Here, you have the option to set the size of the margins around your spreadsheet document. You can increase / decrease the default margin sizes using the upward and downward pointing arrows. You can also change the size of any headers and / or footers in the same way.

            This is often useful if you want each page to accommodate more data when printed – by reducing the size of the margins, your spreadsheet will be able to display more information.
          img: placeholder_icon.svg
        -
          title: Header / Footer
          text: |
            You can use the text entry boxes to type the header / footer you want to display on your spreadsheet. Headers and footers are particularly useful if you want certain information to appear on every page of your document, without having to type it in every time.

            You can also use the Custom Header / Custom Footer buttons to do more with your headers and footers.
          img: placeholder_icon.svg
        -
          title: Sheet
          text: |
            In most cases, you will want to print your entire worksheet – however, if you want to select a particular area to print, you can use this option to do so.

            You can choose to duplicate your titles either at the top or the left of your spreadsheet.

            You also have options to include gridlines and row / column headings, and you can adjust the page order.
          img: placeholder_icon.svg
