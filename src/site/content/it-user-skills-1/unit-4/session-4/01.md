            A pie chart can be used to highlight the different values within a particular set of data. This is a good way to see the different proportions of data that make up the total, as each ‘slice’ of the pie will be sized according to the data it represents.  A pie chart can only be used to show one data series. It is not a tool that can be used to compare two or more sets of data.

          img: placeholder_icon.svg

    title: Selecting data
    theme: t-bg-primary
    copy: |
      Selecting the correct data for your chart is very important; it is the first step in creating any chart or graph.

      If you know that you are going to use the data in a spreadsheet to create a graph then you should make sure that you structure your worksheet in such a way that you will be able to easily select the data that you going to use.

      When it comes to selecting data for charts and graphs, there are many different options available. Select the images below to learn more.
