      [//]: # (You may see a Microsoft Word icon on your computer desktop.

      Once you’ve finished with your first document and you want to create another new document, simply select File – New from the menu at the top of the screen.
      When you select the File – New menu option, a Task Pane will open on the right-hand side of the screen and you will need to select the Blank document option here in order to create your new document.)
