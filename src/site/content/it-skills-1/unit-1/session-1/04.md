        #### Open an existing document in a folder and in Word

        [//]: # (*INCLUDE THIS:**Include:*
        When you save your work, you may choose to file the document into a specific folder on your computer to help you find it more easily if you need to revisit your work at any time.
        For example, if you have saved a file into a folder in your My Documents folder, then you can access this file by:
        Clicking the Start button on your desktop and selecting My Documents from the menu.
        Double-click to open the folder containing your file.
        Double-click the file to open it.)

        [//]: # (*INCLUDE THIS:**Include:* #### Open an existing document in Word
        If you already have the Microsoft Word program open, you can open documents by selecting File – Open from the top menu *Office button – Open in Microsoft Word 2007*. The Open dialog box will appear:
        Simply navigate to the file you want to open using the Look in: drop-down list. Once you’ve found the file, click to select it and then click the Open button. Your chosen file will now open on screen.)

        You will find that these two techniques for opening documents are the same for most other software programs in Windows.

      Once you start adding content to your document, you’re going to want to save the work you have done.  And, the final thing you need to know when working with documents is how to print the work you’ve done.
      
      ### Save your document

      [//]: # (*include this:*
      To save your Word document, you can either click the Save icon: Save icon or select File – Save As from the menu at the top of the screen. The following dialog box will appear on screen:
      By default, documents are saved on the C: drive in the My Documents folder. If you want to save your work somewhere else *such as onto a CD*, you can click to display the Save In: menu to see your other options.
      Use the File name: box to give your document a name that will help you to remember its contents and then click the Save button.
      Once you have saved your document, you can close it. To do this, click the white cross in the top right corner of the screen: Close button 03 . If you have made any further *unsaved changes to your document before closing, Word will prompt you at this point to save your work again before closing.
      You should always use File – Save As when you first save a document. Once you have saved your work with a proper file name, you can then use the Save icon: Save whenever you want to update and save further changes that have been made to the document.)

        ### Print your document

        [//]: # (*INCLUDE THIS:**include:*
        As with saving your document, you have two options when it comes to printing your work.
        You can either click the Print icon: Print icon 03 *In Microsoft Word 2007 the icon is: Print icon 07* or select File – Print  from the top menu.
        The following Print dialog box will appear on screen.
        Here, you will have the option to select which printer you want to use *if you have more than one to choose from!*. You can also choose whether you want to print the whole document, or just a certain number of pages.
        If you want to see what your document will look like before you print it out, you can choose to see a Print Preview using this toolbar button: Print preview. This is a useful thing to do as it gives you a chance to check the layout of your document before printing it. Once you’re happy with the way your document looks, Close the preview and then click the Print icon.)

            Follow these instructions to print folder contents on a PC:

            1. Go to the screen you want to take a screenprint of and press the Print Screen key on your keyboard (you’ll usually find this key in the top right corner of the keyboard, next to the F12 key).
            2. Now open up a blank Word document. Go to the top menu bar and select Edit – Paste (Home – Paste in Microsoft Word 2007). Your screenprint will be pasted in to the blank file.
            3. To save your screenprint, select File – Save As (Office button – Save As in Microsoft Word 2007) from the top menu and give your document a suitable name.
