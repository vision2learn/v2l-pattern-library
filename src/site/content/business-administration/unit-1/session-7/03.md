      ### Unit quiz is different to quick quiz

      Q1. Which of the following must be included in a contract of employment? 
      A. Home address B. Place of work C. Training days 
      The correct answer is B. Place of work 

      Q2. Is the following statement true or false? 
      “Non union representatives tend to have a collective bargaining role.” 
      A. True B. False 
      The correct answer is B. False 

      Q3. Which one of the following is not a reason for exemption under data protection legislation? 
      A. National security
      B. Crime prevention
      C. Embarrassing photo‟s on facebook 
      The correct answer is C. Embarrassing photo‟s on facebook 

      Q4. Is the following statement true or false? 
      “If there is a serious health and safety hazard you should report it to an appropriate manager immediately.” 
      A. True B. False 
      The correct answer is A. True 

      Q5. Is the following statement true or false? 
      “Active listening is best done in a bustling office environment.” 
      A. True B. False 
      The correct answer is B. False 

      Q6. Select one option to complete this sentence  
      "Being honest in the workplace ________________________________." 
      A. Is the behaviour of a loser
      B. Encourages suspicion
      C. Encourages good working relationships 
      The correct answer is C. Encourages good working relationships 

      Q7. Which one of the following should you do if there is a delay in a piece of work which needs to be given to a colleague? 
      A. Pass the piece on when it is eventually finished
      B. Inform the colleague that there is a problem and let them know when the job will be done
      C. Inform the colleague as soon as you know there is a delay and provide a new workable completion time 
      The correct answer is C. Inform the colleague as soon as you know there is a delay and provide a new workable completion time 

      Q8. Is the following statement true or false? 
      “People who continuously improve their performance are more likely to be better paid.” 
      A. True B. False 
      The correct answer is A. True 

      Q9. Which one of the following is not a likely career pathway? 
      A. Resigning
      B. Looking for greater managerial responsibilities
      C. Looking for a chance to specialise (e.g. In business or finance) 
      The correct answer is A. Resigning 

      Q10. Which one of the following should an employee do if the failure to solve a problem quickly or the solution to a problem will impact upon many people? 
      A. Seek assistance
      B. Solve it him/her self
      C. Solve it with permission 
      The correct answer is A. Seek assistance
